# Day 17 — Linear Regression from Scratch

## Objective
Understand how Linear Regression works by implementing it without using machine learning libraries.

## Description
This project manually calculates the slope and intercept using mathematical formulas and predicts output values.

## Steps Performed
- Data loading
- Mean calculation
- Slope computation
- Intercept computation
- Prediction
- Visualization

## Tools Used
Python  
NumPy  
Pandas  
Matplotlib  

## Key Concepts
- Linear Regression equation
- Slope and intercept
- Manual model building

## How to Run
python linear_regression_scratch.py

## Learning Outcome
Gained deep understanding of how Linear Regression works internally without relying on libraries like sklearn.
