# Day 26 — KNN Classifier

## Objective
Build a classification model using K-Nearest Neighbors.

## Description
This project predicts whether a customer will purchase a product using KNN based on Age and Salary.

## Tools Used
Python  
Pandas  
Scikit-learn  

## Key Concepts
- Distance-based learning
- Nearest neighbors
- Feature scaling

## Steps Performed
- Data loading
- Train-test split
- Feature scaling
- Model training
- Prediction
- Evaluation

## How to Run
python knn_classifier.py

## Learning Outcome
Learned how KNN works using distance and how scaling affects model performance.
