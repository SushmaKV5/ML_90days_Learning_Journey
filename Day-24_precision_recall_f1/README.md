# Day 24 — Precision, Recall & F1 Score

## Objective
Understand and calculate key classification evaluation metrics.

## Description
This project computes Precision, Recall, and F1 Score and visualizes them using a bar chart.

## Tools Used
Python  
Pandas  
Scikit-learn  
Matplotlib  

## Metrics Explained
- Precision: Accuracy of positive predictions
- Recall: Ability to find all positives
- F1 Score: Balance between precision and recall

## How to Run
python precision_recall_f1.py

## Learning Outcome
Learned how to evaluate classification models beyond accuracy using advanced metrics.
