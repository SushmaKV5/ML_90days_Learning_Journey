# Day 28 — Student Pass Prediction

## Objective
Build a classification model to predict whether a student will pass based on study habits and academic factors.

## Dataset Features
- StudyHours
- Attendance
- SleepHours
- PreviousScore

## Target
- Pass (1) or Fail (0)

## Steps Performed
- Data loading
- Train-test split
- Feature scaling
- Logistic Regression model
- Prediction
- Evaluation

## Tools Used
Python  
Pandas  
Scikit-learn  

## Model Performance
- Accuracy: High (varies)

## Sample Prediction
Input: StudyHours=6, Attendance=80, Sleep=7, Score=65  
Prediction: Pass

## Learning Outcome
Learned how to build a complete classification pipeline using multiple features.
