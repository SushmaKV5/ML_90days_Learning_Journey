# Day 25 — Decision Tree Classifier

## Objective
Build a Decision Tree model for classification tasks.

## Description
This project uses a Decision Tree Classifier to predict whether a customer will purchase a product.

## Features
- Age
- Salary

## Target
- Purchased (0 or 1)

## Steps Performed
- Data loading
- Train-test split
- Model training
- Prediction
- Evaluation
- Tree visualization

## Tools Used
Python  
Pandas  
Scikit-learn  
Matplotlib  

## Learning Outcome
Learned how Decision Trees work and how to visualize decision-making in Machine Learning.
