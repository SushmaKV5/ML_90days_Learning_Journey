# Day 30 — Feature Normalization Comparison

## Objective
Understand the difference between normalization and standardization.

## Description
This project compares Min-Max Normalization and Standardization on a dataset.

## Techniques Used
- MinMaxScaler
- StandardScaler

## Tools Used
Python  
Pandas  
Scikit-learn  
Matplotlib  

## Key Concepts
- Feature scaling
- Data normalization
- Data standardization

## How to Run
python normalization_comparison.py

## Learning Outcome
Learned how different scaling techniques affect data and when to use each method.
