# Day 14 — Mini EDA Project (Titanic Dataset)

## Objective
Perform Exploratory Data Analysis (EDA) on a real-world dataset to extract insights and understand data patterns.

## Dataset
Titanic dataset from Kaggle.

## Steps Performed
- Data loading and inspection
- Data cleaning (handling missing values)
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Insight generation

## Tools Used
Python  
Pandas  
Matplotlib  
Seaborn  

## Key Insights
- Female passengers had higher survival rate
- First-class passengers had better survival chances
- Fare is correlated with passenger class
- Missing data handling is crucial before modeling

## Learning Outcome
This project demonstrates the complete EDA workflow, which is an essential step before building Machine Learning models.
