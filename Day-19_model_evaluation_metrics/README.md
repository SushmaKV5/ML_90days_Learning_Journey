# Day 19 — Model Evaluation Metrics

## Objective
Evaluate the performance of a Machine Learning model using standard regression metrics.

## Description
This project demonstrates how to calculate MSE, RMSE, and R² Score to measure model performance.

## Tools Used
Python  
Pandas  
NumPy  
Scikit-learn  

## Metrics Explained
- MSE: Measures squared error
- RMSE: Square root of MSE (interpretable error)
- R² Score: Model accuracy measure

## How to Run
python model_evaluation.py

## Learning Outcome
Learned how to evaluate Machine Learning models and interpret performance metrics to improve model accuracy.
