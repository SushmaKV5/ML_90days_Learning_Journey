# Day 20 — Overfitting vs Underfitting

## Objective
Understand the difference between underfitting and overfitting using polynomial regression.

## Description
This project visualizes how model complexity affects performance using different polynomial degrees.

## Experiments
- Degree 1 → Underfitting
- Degree 2 → Good Fit
- Degree 10 → Overfitting

## Tools Used
Python  
NumPy  
Pandas  
Scikit-learn  
Matplotlib  

## Key Concepts
- Underfitting
- Overfitting
- Bias vs Variance
- Model complexity

## How to Run
python overfitting_underfitting.py

## Learning Outcome
Learned how model complexity impacts performance and how to choose the right model to avoid underfitting and overfitting.
