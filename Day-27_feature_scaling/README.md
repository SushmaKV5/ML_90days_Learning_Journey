# Day 27 — Feature Scaling Experiment

## Objective
Understand the importance of feature scaling in Machine Learning.

## Description
This project compares model performance with and without feature scaling using KNN.

## Tools Used
Python  
Pandas  
Scikit-learn  

## Experiments
- KNN without scaling
- KNN with StandardScaler

## Key Concepts
- Feature scaling
- Data normalization
- Impact on model performance

## Results
Scaling significantly improves model accuracy.

## How to Run
python feature_scaling_experiment.py

## Learning Outcome
Learned how feature scaling impacts distance-based models and improves performance.
