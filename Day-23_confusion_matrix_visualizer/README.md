# Day 23 — Confusion Matrix Visualizer

## Objective
Visualize classification model performance using a confusion matrix.

## Description
This project builds a Logistic Regression model and visualizes its performance using a confusion matrix plot.

## Tools Used
Python  
Pandas  
Scikit-learn  
Matplotlib  

## Features
- Model training
- Prediction
- Confusion matrix generation
- Visualization using ConfusionMatrixDisplay

## How to Run
python confusion_matrix_visualizer.py

## Learning Outcome
Learned how to interpret classification results visually using confusion matrices, helping understand model accuracy and errors.
