# Day 18 — Polynomial Regression

## Objective
Understand how to model non-linear relationships using Polynomial Regression.

## Description
This project extends Linear Regression by adding polynomial features to capture curved relationships in data.

## Steps Performed
- Data loading
- Train-test split
- Polynomial feature transformation
- Model training
- Prediction
- Visualization

## Tools Used
Python  
Pandas  
NumPy  
Scikit-learn  
Matplotlib  

## Key Concepts
- Linear vs Non-linear models
- Polynomial features
- Curve fitting

## How to Run
python polynomial_regression.py

## Learning Outcome
Learned how to handle non-linear data by transforming features into polynomial form and improving model performance.
