# Day 13 — Seaborn Pairplot Analysis

## Objective
Visualize relationships between multiple numerical variables using Seaborn pairplots.

## Description
This project generates a pairplot to analyze feature relationships and distributions within the dataset.

## Tools Used
Python  
Pandas  
Seaborn  
Matplotlib  

## Key Concepts
- Pairplot visualization
- Feature relationships
- Exploratory Data Analysis (EDA)

## How to Run
python pairplot_analysis.py

## Learning Outcome
Pairplots allow quick visualization of relationships between multiple features, helping identify correlations and patterns before applying Machine Learning models.
