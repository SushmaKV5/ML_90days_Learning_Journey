# Day 29 — Encoding Categorical Variables

## Objective
Convert categorical (text) data into numerical form for Machine Learning.

## Description
This project demonstrates Label Encoding and One-Hot Encoding techniques.

## Dataset Features
- Gender (categorical)
- City (categorical)
- Experience
- Salary

## Techniques Used
- Label Encoding
- One-Hot Encoding

## Tools Used
Python  
Pandas  

## How to Run
python encoding_categorical.py

## Learning Outcome
Learned how to handle categorical variables and convert them into numerical data for ML models.
