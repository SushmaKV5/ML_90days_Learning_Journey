# Day 16 — Linear Regression Model

## Objective
Build and train a Linear Regression model to predict a continuous variable.

## Description
This project implements a simple Linear Regression model to predict Salary based on Experience.

## Steps Performed
- Data loading
- Feature selection
- Train-test split
- Model training
- Prediction
- Model evaluation
- Visualization

## Tools Used
Python  
Pandas  
Scikit-learn  
Matplotlib  

## Key Concepts
- Linear Regression
- Model training
- Prediction
- Evaluation (MSE, R² Score)

## How to Run
python linear_regression.py

## Learning Outcome
Learned how to build and evaluate a basic Machine Learning model using Linear Regression.
